# 🐠 游戏行为量化多元智能评分系统 · 接入规范

> **文档版本:** v1.0  
> **适用范围:** 前端(Vue 3) + 后端(Python FastAPI)  
> **核心原则:** 所有数据由游戏后台自动采集、自动计算、自动映射，**零人工干预、零主观打分**，数据可直接用于学术量化研究与AI模型训练。

---

## 一、概述

### 1.1 系统定位

在现有《蔚蓝科考基地·重建计划》儿童游戏测评项目中，接入一套 **客观行为量化多元智能评分系统**。该系统通过游戏端实时采集儿童在三个关卡中的自然交互行为数据，经由后台自动计算，生成三个分项得分（S1/S2/S3）和综合潜能得分，最终映射为可视化潜能报告。

### 1.2 数据流架构

```
┌──────────────────────────────────────────────────────────────────┐
│                     行为数据采集层（前端）                        │
│                                                                  │
│  Level 1 (珊瑚公寓)     Level 2 (洋流电网)     Level 3 (议事厅)  │
│  ├─ 关卡完成耗时         ├─ 关卡完成耗时        ├─ 关卡完成耗时   │
│  ├─ 无效点击次数         ├─ 无效点击次数        └─ 前端暂不采集   │
│  ├─ 无效拖拽次数         ├─ 无效拖拽次数                          │
│  ├─ 总操作次数           ├─ 总操作次数          ← 跳关行为统一采集 │
```

## 二、游戏端实时采集的行为数据（三关通用 + 关卡特定）

### 2.1 各关卡完成耗时（三关均需采集）

每条记录必须包含以下字段：

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `level_id` | string | 关卡标识 | `"LEVEL_1"` |
| `duration_seconds` | int | 进入关卡至通关的总耗时(秒) | `127` |

**采集时机：** 关卡计时器在关卡加载完成时（故事弹窗关闭/新手引导开始）启动 `gameStartTime`，通关/跳过关卡时记录。

**前端现有代码对照：**
- LevelOne: `const duration = Math.floor((Date.now() - gameStartTime.value) / 1000)` → 已实现
- LevelTwo: `const dur = Math.floor((Date.now() - gameStartTime.value) / 1000)` → 已实现  
- LevelThree: `const dur = Math.floor((Date.now() - gameStartTime.value) / 1000)` → 已实现

### 2.2 前两关（Level 1 & Level 2）无效交互行为数据

统计第1、2关的"无效操作"数据，用于计算专注自控智能得分 S2。

#### 2.2.1 无效操作类型定义

| 操作类型 | 定义 | Level 1 示例 | Level 2 示例 |
|----------|------|-------------|-------------|
| **无意义点击** | 点击无交互反馈的目标区域（空白区、装饰元素、已完成区域） | 点击海洋空地的装饰海草 | 点击已被占用的空格 |
| **空白点击** | 点击没有任何可操作内容的位置 | 点击进度面板空白处 | 点击网格外区域 |
| **随意拖拽** | 拖拽后未放置在有效区域即释放 | 将生物拖到海洋外松开 | 将管道拖到网格外松开 |
| **无效拖动** | 拖拽到不合理/不允许的位置 | 把海葵拖到非沙地区 | 把管道放在障碍物上 |

#### 2.2.2 需要采集的统计字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `meaningless_clicks` | int | 无意义点击次数 |
| `blank_clicks` | int | 空白点击次数 |
| `random_drags` | int | 随意拖拽次数 |
| `invalid_drops` | int | 无效放置/拖动次数 |
| `total_operations` | int | 总操作次数（含有效+无效） |

**计算公式：** `无效操作占比 Rp = (meaningless_clicks + blank_clicks + random_drags + invalid_drops) / total_operations`

### 2.3 跳关行为数据（三关通用）

统计本次测评中 **未完成当前关卡直接跳转下一关的总次数**。

#### 2.3.1 跳关判定标准

- **Level 1：** 未完成所有4组配对（4条规则未全部满足）即点击"前往下一关"
- **Level 2：** 电路未连通（`isConnected === false`）即点击"前往下一关"
- **Level 3：** 和解度未达到100%或对话轮次未完成即点击"前往下一关"
- **调试栏跳转：** 通过底部调试导航栏直接跳过关卡

> ⚠️ **注意：** 前三项属于"主动放弃"，调试栏跳转属于"开发模式"。生产环境下应只统计前三项，但开发阶段建议一并采集以便验证。

#### 2.3.2 采集方式

**方案 A（推荐）：在 App.vue 全局拦截**

在 `App.vue` 的 `handleLevelComplete` 或 `handleGoLevel` 中增加判断：

```javascript

  // ... 检测逻辑
  skipLevelCount.value++
}

// ✏️ 在 handleLevelComplete 中增加"未完成即跳转"的检测
```

**方案 B（推荐）：每关单独记录**

每关在 `goNextLevel()` 中增加条件判断：


## 三、后台自动计算三个分项得分（S1/S2/S3）

### 3.1 常模配置（关键参数）

系统使用 **年龄段常模均值 T0** 作为 S1 耗时评分的基准参照：

```python
# scoring_config.py
NORM_CONFIG = {
    "age_norm_seconds": {
        "6":   {"level1": 300, "level2": 480, "level3": 600},  # 6岁常模
        "7":   {"level1": 260, "level2": 420, "level3": 540},
        "8":   {"level1": 220, "level2": 360, "level3": 480},
        "9":   {"level1": 190, "level2": 310, "level3": 420},
        "10":  {"level1": 160, "level2": 270, "level3": 360},
    },
    # 默认常模（未获取到年龄时使用）
    "default_norm_seconds": {
        "level1": 240,
        "level2": 380,
        "level3": 500,
    },
}
```

### 3.2 S1：关卡耗时得分 —— 对应「逻辑空间智能」

| 项目 | 内容 |
|------|------|
| **对应智能** | 逻辑数学智能、视觉空间智能 |
| **评分维度** | 思维效率、任务加工速度 |
| **计算方式** | 以同年龄段常模均值 T0 为基准，计算相对耗时比 |

#### 3.2.1 计算公式

```
Rt = 实际总耗时 / 常模总耗时

其中：
  实际总耗时 = Level1.duration + Level2.duration + Level3.duration（三关合计）
  常模总耗时 = NORM_CONFIG[age].level1 + NORM_CONFIG[age].level2 + NORM_CONFIG[age].level3
```

#### 3.2.2 分段规则（输出 1-5 整数分）

| 条件 | S1 得分 | 标签 |
|------|---------|------|
| Rt ≤ 0.8 | **5分** | 思维效率极高 |
| 0.8 < Rt ≤ 1.0 | **4分** | 思维效率良好 |
| 1.0 < Rt ≤ 1.2 | **3分** | 思维效率中等 |
| 1.2 < Rt ≤ 1.5 | **2分** | 思维效率偏低 |
| Rt > 1.5 | **1分** | 思维效率需关注 |

#### 3.2.3 后端实现示意

```python
def calc_S1(durations: dict, age: str) -> int:
    """计算 S1 关卡耗时得分"""
    config = NORM_CONFIG.get(age, NORM_CONFIG["default"])
    
    actual = durations.get("level1", 0) + durations.get("level2", 0) + durations.get("level3", 0)
    norm = config["level1"] + config["level2"] + config["level3"]
    
    if norm <= 0:
        return 3
    
    Rt = actual / norm
    
    if Rt <= 0.8:
        return 5
    elif Rt <= 1.0:
        return 4
    elif Rt <= 1.2:
        return 3
    elif Rt <= 1.5:
        return 2
    else:
        return 1
```

### 3.3 S2：无效操作得分 —— 对应「专注自控智能」

| 项目 | 内容 |
|------|------|
| **对应智能** | 内省智能、注意力自控能力 |
| **评分维度** | 专注度、冲动控制、任务适应 |
| **计算方式** | 统计 Level 1 + Level 2 的无效操作占比 |

#### 3.3.1 计算公式

```
Rp = (Level1无效操作总数 + Level2无效操作总数) / (Level1总操作数 + Level2总操作数)

其中：
  无效操作总数 = meaningless_clicks + blank_clicks + random_drags + invalid_drops
  总操作数     = total_operations
```

#### 3.3.2 分段规则（输出 1-5 整数分）

| 条件 | S2 得分 | 标签 |
|------|---------|------|
| Rp ≤ 10% | **5分** | 专注自控力极强 |
| 10% < Rp ≤ 20% | **4分** | 专注自控力良好 |
| 20% < Rp ≤ 35% | **3分** | 专注自控力中等 |
| 35% < Rp ≤ 50% | **2分** | 专注自控力偏弱 |
| Rp > 50% | **1分** | 专注自控力需关注 |

#### 3.3.3 后端实现示意

```python
def calc_S2(level1_metrics: dict, level2_metrics: dict) -> int:
    """计算 S2 无效操作得分"""
    def get_invalid(m):
        return (m.get("meaningless_clicks", 0) + 
                m.get("blank_clicks", 0) + 
                m.get("random_drags", 0) + 
                m.get("invalid_drops", 0))
    
    def get_total(m):
        return m.get("total_operations", 0)
    
    invalid = get_invalid(level1_metrics) + get_invalid(level2_metrics)
    total = get_total(level1_metrics) + get_total(level2_metrics)
    
    if total <= 0:
        return 3
    
    Rp = invalid / total
    
    if Rp <= 0.10:
        return 5
    elif Rp <= 0.20:
        return 4
    elif Rp <= 0.35:
        return 3
    elif Rp <= 0.50:
        return 2
    else:
        return 1
```

### 3.4 S3：跳关坚持得分 —— 对应「意志坚持智能」

| 项目 | 内容 |
|------|------|
| **对应智能** | 意志坚持性、规则执行能力、抗挫折能力 |
| **评分维度** | 任务坚持度、规则内化程度 |
| **计算方式** | 统计本次测评中未完成当前关卡直接跳转下一关的总次数 |

#### 3.4.1 分段规则（输出 1-5 整数分）

| 条件 | S3 得分 | 标签 |
|------|---------|------|
| 0 次跳关（全部通关完成） | **5分** | 意志坚持力极强 |
| 1 次跳关 | **4分** | 意志坚持力良好 |
| 2 次跳关 | **3分** | 意志坚持力中等 |
| 3 次跳关 | **2分** | 意志坚持力偏弱 |
| ≥ 4 次跳关 | **1分** | 意志坚持力需关注 |

> **注意：** 如果玩家完全通关所有三关（未使用任何跳关方式），则 S3 = 5分。  
> 如果玩家只完成部分关卡就退出，剩余关卡视为"跳关"，计入跳关次数。

#### 3.4.2 后端实现示意

```python
def calc_S3(skip_count: int) -> int:
    """计算 S3 跳关坚持得分"""
    if skip_count == 0:
        return 5
    elif skip_count == 1:
        return 4
    elif skip_count == 2:
        return 3
    elif skip_count == 3:
        return 2
    else:  # >= 4
        return 1
```

## 四、综合潜能总分计算公式

### 4.1 综合得分

> **注意：** 以下所有 S1/S2/S3 均先以 1-5 整数分计，再进行加权计算。

```
综合得分 S = 0.3 × S1 + 0.4 × S2 + 0.3 × S3
```

- 结果保留 **1 位小数**
- 分值区间：**1.0 – 5.0**
- S2（专注自控智能）权重最高（0.4），体现专注力在儿童发展评估中的核心地位

### 4.2 自动能力等级判定

| 综合得分范围 | 等级 | 含义 | 报告展示色 |
|-------------|------|------|-----------|
| 4.2 – 5.0 | **A级** | 优秀潜能 | 🟢 翡翠绿 |
| 3.4 – 4.1 | **B级** | 良好潜能 | 🔵 天蓝 |
| 2.6 – 3.3 | **C级** | 中等潜能 | 🟡 琥珀 |
| 1.8 – 2.5 | **D级** | 待提升潜能 | 🟠 橙 |
| 1.0 – 1.7 | **E级** | 薄弱潜能 | 🔴 玫瑰红 |

### 4.3 后端实现

```python
def calc_comprehensive_score(S1: int, S2: int, S3: int) -> dict:
    """计算综合得分和等级"""
    S = round(0.3 * S1 + 0.4 * S2 + 0.3 * S3, 1)
    
    if S >= 4.2:
        level = "A级"
        label = "优秀潜能"
        color = "#10b981"
    elif S >= 3.4:
        level = "B级"
        label = "良好潜能"
        color = "#0ea5e9"
    elif S >= 2.6:
        level = "C级"
        label = "中等潜能"
        color = "#f59e0b"
    elif S >= 1.8:
        level = "D级"
        label = "待提升潜能"
        color = "#f97316"
    else:
        level = "E级"
        label = "薄弱潜能"
        color = "#f43f5e"
    
    return {
        "comprehensive_score": S,
        "level": level,
        "label": label,
        "color": color,
        "scores": {
            "S1_logical_spatial": S1,
            "S2_focus_self_control": S2,
            "S3_persistence": S3,
        }
    }
```

### 9.2 quantitative_scoring.py 完整实现

```python
"""
🐬 游戏行为量化评分引擎
纯客观行为数据自动计算，零人工干预。

计算流程:
  原始行为数据 → S1/S2/S3 (1-5分) → 综合得分 → 等级判定 → 评语生成
"""

from .scoring_config import NORM_CONFIG, S1_TEMPLATES, S2_TEMPLATES, S3_TEMPLATES


def calc_S1(level1_duration: int, level2_duration: int, level3_duration: int, age: str = "8") -> int:
    """
    关卡耗时得分 → 逻辑空间智能
    基于年龄段常模均值的相对耗时比
    """
    config = NORM_CONFIG.get(age, NORM_CONFIG["default"])
    actual = level1_duration + level2_duration + level3_duration
    norm = config["level1"] + config["level2"] + config["level3"]

    if norm <= 0:
        return 3

    Rt = actual / norm

    if Rt <= 0.8:
        return 5
    elif Rt <= 1.0:
        return 4
    elif Rt <= 1.2:
        return 3
    elif Rt <= 1.5:
        return 2
    else:
        return 1


def calc_S2(level1_metrics: dict, level2_metrics: dict) -> int:
    """
    无效操作得分 → 专注自控智能
    基于无效操作占比
    """
    def get_invalid(m):
        return (m.get("meaningless_clicks", 0) +
                m.get("blank_clicks", 0) +
                m.get("random_drags", 0) +
                m.get("invalid_drops", 0))

    def get_total(m):
        return m.get("total_operations", 0)

    invalid = get_invalid(level1_metrics) + get_invalid(level2_metrics)
    total = get_total(level1_metrics) + get_total(level2_metrics)

    if total <= 0:
        return 3

    Rp = invalid / total

    if Rp <= 0.10:
        return 5
    elif Rp <= 0.20:
        return 4
    elif Rp <= 0.35:
        return 3
    elif Rp <= 0.50:
        return 2
    else:
        return 1


def calc_S3(skip_count: int) -> int:
    """跳关坚持得分 → 意志坚持智能"""
    if skip_count == 0:
        return 5
    elif skip_count == 1:
        return 4
    elif skip_count == 2:
        return 3
    elif skip_count == 3:
        return 2
    else:
        return 1


def calc_comprehensive(S1: int, S2: int, S3: int) -> dict:
    """
    计算综合得分和等级
    公式: S = 0.3*S1 + 0.4*S2 + 0.3*S3
    """
    score = round(0.3 * S1 + 0.4 * S2 + 0.3 * S3, 1)

    if score >= 4.2:
        level_info = {"level": "A级", "label": "优秀潜能", "color": "#10b981"}
    elif score >= 3.4:
        level_info = {"level": "B级", "label": "良好潜能", "color": "#0ea5e9"}
    elif score >= 2.6:
        level_info = {"level": "C级", "label": "中等潜能", "color": "#f59e0b"}
    elif score >= 1.8:
        level_info = {"level": "D级", "label": "待提升潜能", "color": "#f97316"}
    else:
        level_info = {"level": "E级", "label": "薄弱潜能", "color": "#f43f5e"}

    return {
        "comprehensive_score": score,
        **level_info,
    }


def generate_commentary(S1: int, S2: int, S3: int) -> dict:
    """基于得分生成个性化评语"""
    return {
        "S1_commentary": S1_TEMPLATES.get(S1, ""),
        "S2_commentary": S2_TEMPLATES.get(S2, ""),
        "S3_commentary": S3_TEMPLATES.get(S3, ""),
    }


def generate_quantitative_report(request_data: dict) -> dict:
    """
    主入口：生成完整量化评分报告
    
    参数格式:
    {
        "student_id": "stu_9527",
        "age": "8",
        "level1_metrics": {...},
        "level2_metrics": {...},
        "level3_metrics": {...},
        "total_skip_count": 0,
    }
    """
    l1 = request_data.get("level1_metrics", {})
    l2 = request_data.get("level2_metrics", {})
    l3 = request_data.get("level3_metrics", {})
    age = request_data.get("age", "8")
    skip_count = request_data.get("total_skip_count", 0)

    # 计算三项得分
    S1 = calc_S1(
        l1.get("duration_seconds", 0),
        l2.get("duration_seconds", 0),
        l3.get("duration_seconds", 0),
        age,
    )
    S2 = calc_S2(l1, l2)
    S3 = calc_S3(skip_count)

    # 综合得分
    comprehensive = calc_comprehensive(S1, S2, S3)

    # 评语
    commentary = generate_commentary(S1, S2, S3)

    return {
        "student_id": request_data.get("student_id", ""),
        "age": age,
```

## 十一、开发约束

### 11.1 数据客观性约束

1. **禁止人工干预**：不允许老师、家长或测评员在任何环节手动调整分数
2. **禁止主观打分**：所有评分基于预设分段规则（if-then 或 lookup table），不允许人工评分界面
3. **禁止安慰分**：不得因为儿童年龄小或表现不佳而手动加分
4. **数据可追溯**：每个得分必须能追溯到原始行为数据，支持学术复查
5. **版本锁定**：常模配置和分段规则必须有版本号，修改规则必须升版本号

### 11.2 数据可用性约束

1. **完备性**：Level 1 和 Level 2 必须同时上报完整的行为数据（含无效操作统计），S2 才能计算
2. **降级策略**：如果某关卡数据缺失（例如网络问题未上报），该关卡对应的指标用默认值（S=3分）填充
3. **异常值处理**：如果 `total_operations = 0`（没有操作记录），S2 默认返回 3 分
4. **边界值处理**：`duration_seconds` 不得超过 3600 秒（1小时），超过按 3600 计算

### 11.3 版本与扩展性

1. 常模数据应存储在配置文件中，支持通过管理后台更新
2. 分段规则的阈值应支持动态配置，方便后续依据实证数据调整
3. 评语模板应以 JSON 文件存储，支持版本管理和多语言扩展
4. 评分引擎应支持 A/B 测试模式，同时运行新旧两套评分规则并对比输出
