# 🐬 蔚蓝深海基地 · 多维度差异性测试报告

> **测试日期**: 2026-07-26  
> **测试版本**: 游戏行为量化评分系统 v2  
> **测试范围**: 10名模拟玩家 × 3关卡 × 评分引擎  
> **核心关注**: 玩家差异性区分度 & 第三关敏感/脏话输入处理 & 边界条件

---

## 一、测试方法论

### 1.1 测试对象设计

| 维度   | 覆盖用例数 | 说明                                |
| ---- | ----- | --------------------------------- |
| 年龄覆盖 | 5个年龄段 | 6岁 / 7岁 / 8岁 / 9岁 / 10岁           |
| 行为类型 | 6种画像  | 优秀型 / 好动型 / 敏感型 / 低龄型 / 冲动型 / 消极型 |
| 边界条件 | 3种极端  | 极速通关 / 极慢高失败 / 完全跳关               |
| 脏话输入 | 1个专项  | 第三关对话阶段输入多种脏话/敏感词汇                |

### 1.2 评分体系说明

**量化评分（v2）**：

```
S1 逻辑空间智能 → 耗时比 Rt = 实际耗时 / 年龄常模耗时
S2 专注自控智能 → 无效占比 Rp = 无效操作 / 总操作数
S3 意志坚持智能 → 基于跳关次数 + 完全跳过判定
S4 社交调解智能 → 基于和解度 + 对话轮次 + 情绪/方案质量

综合分 S = 0.25×S1 + 0.30×S2 + 0.25×S3 + 0.20×S4
等级: A(≥4.2) B(≥3.4) C(≥2.6) D(≥1.8) E(<1.8)
```
