## 一、技术栈详细方案

### 1.1 核心框架选型

| 层级 | 技术选型 | 版本 | 选型理由 |
|------|---------|------|---------|
| **前端框架** | Next.js 14 (App Router) | 14.2+ | 支持SSR/SSG/ISR，内置路由、API Routes，适合游戏+后台一体化部署 |
| **UI 运行时** | React 18 | 18.3+ | 组件化开发，支持拖拽、动画等复杂交互 |
| **类型系统** | TypeScript 5 | 5.4+ | 全栈类型安全，减少运行时错误 |
| **游戏引擎层** | Custom React Game Engine (自研轻量级) | - | 使用 React + Canvas 混合架构，DOM 用于 UI，Canvas 用于游戏场景 |
| **状态管理** | Zustand | 4.5+ | 轻量、无 boilerplate、支持中间件（persist、devtools） |
| **动画引擎** | Framer Motion + GSAP | 11.x / 3.12+ | Framer Motion 用于 UI 过渡动画，GSAP 用于 Canvas 骨骼动画 |
| **拖拽系统** | @dnd-kit (core + sortable + utils) | 6.1+ | 专为 React 设计的拖拽库，支持自定义碰撞检测、吸附网格 |
| **LLM 集成** | OpenAI API / 本地 LLM (可选) | - | **所有 AI 智能体的推理引擎**：海豚助手的引导对话、NPC角色对玩家输入的动态回应、第三关文本情感分析 |
| **AI Agent 框架** | Vercel AI SDK (ai) | 4.0+ | 流式文本响应、Tool Calling、多 Agent 编排，统一管理所有 AI 智能体 |
| **流式传输** | Server-Sent Events (SSE) | - | AI 助手的实时文字逐字打印效果，增强沉浸感 |

## 四、游戏引擎关键算法

### 4.1 网格吸附拖拽算法 (useDraggableGrid)

```
输入: 拖拽元素的像素坐标 (x, y)
     网格的起始坐标 (gridOriginX, gridOriginY)
     网格单元大小 (cellWidth, cellHeight)

流程:
  1. 计算相对偏移: relX = x - gridOriginX, relY = y - gridOriginY
  2. 计算网格下标: col = floor(relX / cellWidth), row = floor(relY / cellHeight)
  3. 边界裁剪: col = clamp(col, 0, maxCols-1), row = clamp(row, 0, maxRows-1)
  4. 碰撞检测: 检查目标格子是否被占用或为障碍物
  5. 物理重力: 如果目标栏位下方有空格，自动下沉 (第一关)
  6. 返回吸附后的中心坐标: snapX = gridOriginX + col * cellWidth + cellWidth/2
                           snapY = gridOriginY + row * cellHeight + cellHeight/2
```

### 4.2 管道连通性验证 (pipeValidator.ts) — BFS

```
输入: grid: (PipePiece | null)[][], 起点 start, 终点 end
算法: BFS (广度优先搜索)

1. 遍历网格，为每个管道节点计算其"连接端口"（Up/Down/Left/Right四个方向是否有开口）
2. 从起点开始BFS：
   a. 出队当前节点 (r, c)
   b. 检查其四个方向端口
   c. 若某方向有开口，检查相邻格子在该方向是否有对应的开口
   d. 若连通且未访问，入队相邻节点
3. 若 BFS 能到达终点，则电路连通 ✅
4. 路径回溯可得到"玩家实际路径长度" vs "理论最短路径" 的对比
```

### 4.3 多元智能评分引擎 (scoringEngine.ts)

```
输入: 三个关卡的所有 metric 数据
输出: 五个维度的标准化评分 (0-100)

评分公式:

空间智能 = w1 * (1 - rebuildCount/基准值) * 50 + 50
         + w2 * (心理旋转正确率) * 50
         + w3 * (管道旋转效率) * 50
  其中: w1=0.4 (搭建重构), w2=0.3 (心理旋转), w3=0.3 (管道规划)

逻辑-数理智能 = w1 * (1 - (实际管道数/最优管道数 - 1) / 偏差容忍度) * 50 + 50
              + w2 * (卡顿时间评分) * 50
              + w3 * (路径最优性评分) * 50

自然观察智能 = w1 * (首次安置成功率) * 100
             + w2 * (匹配正确率) * 100

人际智能 = w1 * (情绪辨识准确率) * 100
         + w2 * (双赢方案选择率) * 100

语言智能 = w1 * (情感倾向分) * 50 + 50
         + w2 * (字数评分) * 25
         + w3 * (逻辑性评分, LLM评估) * 25
```

### 6.6 NPC 对话引擎（NPCDialogueEngine.ts）

```typescript
/**
 * NPCDialogueEngine：NPC 对话生成的统一引擎
 * 负责根据触发事件，路由到对应的 Agent，合并 Prompt 并生成回应
 */
class NPCDialogueEngine {
  private agents: Map<string, BaseAgent>;
  private context: DialogueContext;
  private llmService: LLMService;

  constructor() {
    // 注册两个 NPC Agent
    this.agents.set('hermitCrab', new HermitCrabAgent());
    this.agents.set('parrotfish', new ParrotfishAgent());
  }

  /**
   * 生成 NPC 对玩家输入的回应
   */
  async generateResponse(params: {
    npcId: 'hermitCrab' | 'parrotfish';
    playerMessage: string;
    currentRound: number;
    contextSnapshot: any;
  }): Promise<{
    text: string;             // NPC 的回应文本（通过 SSE 流式传输）
    angerDelta: number;       // 愤怒值变化
    confidence: number;       // LLM 生成置信度
  }> {
    const agent = this.agents.get(params.npcId);
    const prompt = agent.buildPrompt({
      personality: this.getPersonality(params.npcId),
      angerLevel: this.context.getCurrentAnger(params.npcId),
      identifiedEmotions: this.context.getIdentifiedEmotions(params.npcId),
      currentRound: params.currentRound,
      playerMessage: params.playerMessage,
    });

    // 使用 SSE 流式调用 LLM
    const stream = await this.llmService.streamChat({
      systemPrompt: prompt,
      messages: this.context.getConversationHistory(params.npcId),
      temperature: 0.8,     // 给 NPC 一点随机性，让对话更自然
    });

    // 后处理：解析愤怒值变化、更新对话上下文
    const response = await this.postProcess(stream, params);
    
    // 更新对话记忆
    this.context.addNpcResponse(params.npcId, response.text);
    
    return response;
  }

  /**
   * 检测对话是否需要干预（防重复/防死循环）
   */
  private detectAnomalies(npcId: string, generatedText: string): boolean {
    // 检查是否和上一轮回复高度重复
    const lastResponse = this.context.getLastNpcResponse(npcId);
    if (this.textSimilarity(generatedText, lastResponse) > 0.85) {
      return true;  // 触发干预
    }
    // 检查是否长度异常
    if (generatedText.length < 5 || generatedText.length > 200) {
      return true;
    }
    return false;
  }
}
```

## 十、儿童友好交互规范

1. **按钮尺寸 ≥ 44px** (WCAG触控指南)
2. **所有交互都有声音反馈**（拖拽音效、放置成功、错误提示）
3. **文字使用超大字号的圆体字**（推荐: ZCOOL KuaiLe 或 站酷快乐体）
4. **错误不惩罚**：放错位置只有温柔的提示泡泡，没有扣分警告
5. **AI海豚持续鼓励**：每步操作都有正面反馈
6. **色盲友好**：不使用颜色作为唯一信息载体，配合图标和文字
7. **AI 回应延迟展示**：NPC 回应逐字显示（SSE流式），与角色口型动画同步，延迟 > 300ms 时显示"..."等待泡泡
8. **对话历史可回溯**：点击 NPC 气泡可回放前几轮的对话（语音朗读功能可选）
