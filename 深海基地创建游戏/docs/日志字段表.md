# 🐬 蔚蓝深海基地 · 数据日志字段表

## 一、会话级字段（顶层请求）

| 字段 | 类型 | 说明 | 来源 |
|------|------|------|------|
| `session_id` | `string` | 会话唯一标识 | 前端生成 `Date.now()` + 随机串 |
| `student_id` | `string` | 学生/玩家 ID | 默认 `"stu_9527"` |
| `timestamp` | `string` (ISO8601) | 提交时间戳 | `new Date().toISOString()` |
| `level` | `enum` | 关卡：`LEVEL_1` / `LEVEL_2` / `LEVEL_3` | 前端提交 |
| `duration_seconds` | `int` | 关卡耗时（秒） | `Date.now() - gameStartTime` |

## 二、第一关 · 珊瑚公寓（`raw_metrics`）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `block_drag_count` | `int` | 0 | 拖拽操作总次数 |
| `species_placement_attempts` | `int` | 0 | 放置尝试次数（含失败） |
| `block_gravity_fall_failures` | `int` | 0 | 移除/纠正次数（空间修正） |
| `removal_count` | `int` | 0 | 删除/撤消次数 |
| `check_attempts` | `int` | 0 | 提交「检查」次数 |
| `successful_pairs` | `int` | 0 | 成功配对数（0-4） |
| `total_errors` | `int` | 0 | 未正确配对数 |
| `pair_details` | `array` | `[]` | 4 组配对详情（见下方） |
| `check_history` | `array` | `[]` | 每次检查的快照日志（见下方） |

### `pair_details[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 配对 ID：`clownfish_anemone` / `garden_eel` / `shrimp_goby` / `remora_turtle` |
| `label` | `string` | 中文标签，如 `"🐠双锯鱼 🤝 🌸海葵"` |
| `done` | `boolean` | 配对是否成功 |

### `check_history[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| `time` | `int` | 检查时刻时间戳 |
| `all_done` | `boolean` | 本轮是否全部正确 |
| `pairs` | `array` | 本轮检查时每对的状态（同 `pair_details` 结构） |

## 六、第三关对话 API

**`POST /api/assessment/level3-chat`**

### 请求体

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | `string` | 会话 ID |
| `student_input` | `string` | 玩家输入的文本 |
| `current_round` | `int` | 当前轮数 |
| `current_harmony` | `int` | 当前和解度 |
| `chat_history` | `array` | 历史对话对 |
| `current_keke_anger` | `int` | 壳壳当前愤怒值 |
| `current_caicai_anger` | `int` | 彩彩当前愤怒值 |

### `chat_history[]`

| 字段 | 类型 | 说明 |
|------|------|------|
| `student` | `string` | 玩家说的话 |
| `keke` | `string` | 壳壳的回复 |
| `caicai` | `string` | 彩彩的回复 |

### 响应体

| 字段 | 类型 | 说明 |
|------|------|------|
| `new_harmony` | `int` | 更新后的和解度 |
| `keke_mood` | `string` | 壳壳情绪：`happy` / `reflective` / 其他 |
| `caicai_mood` | `string` | 彩彩情绪：`happy` / `reflective` / 其他 |
| `keke_reply` | `string` | 壳壳的回复文本 |
| `caicai_reply` | `string` | 彩彩的回复文本 |
| `momo_intervention_needed` | `bool` | 是否需要沫沫介入总结 |
| `momo_reply` | `string` \| `null` | 沫沫总结语 |

## 七、多维潜能报告

**`POST /api/assessment/report`**

### 请求体

| 字段 | 类型 | 说明 |
|------|------|------|
| `session_id` | `string` | 报告会话 ID |
| `student_id` | `string` | 学生 ID |
| `level1_metrics` | `object` | 第一关 `raw_metrics` |
| `level2_metrics` | `object` | 第二关 `raw_metrics` |
| `level3_metrics` | `object` | 第三关 `raw_metrics` |
| `level3_dialogue` | `array` | 第三关完整对话记录 |

### 报告响应结构（Python 引擎 `assessment_engine.py`）

| 字段 | 类型 | 子项 | 说明 |
|------|------|------|------|
| `dimension_scores` | `object` | `空间视觉智能`、`自然观察智能`、`逻辑数理智能`、`人际社交智能`、`语言表达智能`、`专注力与执行能力` | 每项 1.0~10.0 |
| `dimension_analysis` | `object` | 同上六维 | 每项一段 AI 分析文本 |
| `chexi` | `object` | `task_persistence`、`flexibility`、`anti_distraction`、`multi_step_planning`、`experience_learning` | CHEXI 执行功能评分 1~10 |
| `erikson` | `object` | `diligence`、`confidence` | 埃里克森人格品质 1~10 |
| `temperament` | `object` | `label`、`desc`、`dimensions` | 托马斯-切斯先天气质分类 |
| `top3_strengths` | `array` | `[标签, 分数]` 三元组 | 前三优势维度 |
| `weaknesses` | `array` | 待发展领域列表 | 低于阈值项 |
| `strength_summary` | `string` | — | 天赋优势总结段落 |
| `weakness_analysis` | `string` | — | 潜能待发展分析段落 |
| `cognitive_traits` | `string` | — | 认知与执行功能特质分析 |
| `dialogue_analysis` | `string` | — | 对话行为分析 |
| `suggestions` | `string` | — | 个性化培养建议 |

## 八、UI 聚合字段（传给颁奖页 / 报告页）

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|

| `level1_errors` | `int` | Level 1 `emit` | 第一关错误数 |
| `level1_raw` | `object` | Level 1 `raw_metrics` | 第一关原始指标全量 |
| `level2_duration` | `int` | Level 2 `emit` | 第二关用时（秒） |
| `level2_pipes_used` | `int` | Level 2 `emit` | 第二关管道使用数 |
| `level2_raw` | `object` | Level 2 `raw_metrics` | 第二关原始指标全量 |

| `level3_dialogue` | `array` | Level 3 `chatMessages` | 完整对话记录 |
