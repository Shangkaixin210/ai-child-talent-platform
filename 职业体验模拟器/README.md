# 职业体验模拟器

“AI 伯乐计划——AI 天赋发现系统”的职业体验模块原型。面向小学高年级至初中学生，通过职业日常、情境任务、AI 导师引导和探索报告，记录学生在不同任务中的行为证据与能力线索。

> 当前为展示与验证原型。系统输出的是基于任务表现的能力线索和成长建议，不直接给出“适合某职业”的结论。

## 已有功能

- 职业选择与儿童友好的职业岛入口；
- 多职业职业日常与情境体验：社区医生、消防员、小学教师、报社记者、餐厅厨师、动物保护员等；
- 任务中的过程记录：完成阶段、互动次数、专注时长、提示、重试、调整、路线/对话结果；
- AI 导师的引导式追问与即时反馈；
- 基于 ECD 的证据链：任务 → 行为 → 原始记录 → 规则命中 → 能力线索 → 成长建议；
- 8–11 岁与 12–14 岁的分层证据判定；
- 学生探索中心、职业地图、历史体验与最终探索报告；
- 教师/家长观察入口：查看跨职业证据、过程数据、报告状态与异常提醒；
- 未成年人内容安全：隐私信息、不当/无关输入、低参与、情绪或高风险输入的门控与温和处理。

## 技术栈

- 后端：Python、FastAPI、SQLAlchemy、SQLite、Pydantic；
- 页面：HTML、CSS、原生 JavaScript、Jinja2 模板；
- 语音：Edge TTS（浏览器语音作为备用）；
- 数据：本地 SQLite 数据库；
- 图片：本地静态资源，包含职业角色、情境与任务插图。

## 本地运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

如需使用 AI 或语音相关配置，请参考 `.env` 中已有的本地配置。不要提交真实密钥、账号或个人信息。

### 3. 启动服务

```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

浏览器打开：`http://127.0.0.1:8000/`

## 数据与评价说明

系统不会将单次选择或回答长度直接视为能力。评价优先使用任务相关的直接操作证据（如路线规划、排序、对话调整）、任务相关的文本解释和跨任务重复出现的行为线索。

- 单次选择：弱证据；
- 清晰、任务相关的解释：中等证据；
- 职业日常中的路线、排序、搭建、对话调整等：较强证据；
- 低参与、隐私/不当输入、情绪安全关注：进入相应门控，不生成普通能力结论。

完整规则见项目文档《职业体验模拟器评价机制说明》。

## 合并到总平台时的注意事项

当前模块是独立 FastAPI 原型。接入总平台前，请先确认：

1. 总平台的前后端技术栈、目录结构和路由规范；
2. 用户身份、登录态、权限与学生/教师/家长角色接口；
3. 日志、报告和异常事件的数据表或 API 规范；
4. 静态资源、环境变量与部署方式。

迁移时保留 `templates/`、`static/`、核心业务逻辑和数据结构；按总平台规范逐步改造页面入口与 API。不要直接覆盖总项目的 `src/`、`public/` 或配置文件。

## 不应提交到仓库的内容

请在总项目 `.gitignore` 中排除：

```text
.env
venv/
vendor/
__pycache__/
*.pyc
career_sim.db
*.db

*.mp3
```

涉及真实学生的体验记录、联系方式、教师账号、密钥和本地生成语音文件均不应上传。
